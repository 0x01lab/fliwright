Fliwright 可视化编辑器 — 三种布局方案

基于 VS Code Webview Editor Tab，双击测试文件时打开

方案 A：时间轴式（推荐）

左侧纵向时间轴展示语义步骤，右侧截图预览。类似 Playwright Trace Viewer 的布局。

优点

  • 直觉强，从上到下就是操作顺序
  • 截图始终可见，上下文清晰
  • 展开/折叠子步骤天然适合纵向布局

缺点

  • 步骤多时需要滚动
  • 水平空间利用不如分栏

方案 B：分栏卡片式

三栏布局：左侧步骤列表 → 中间截图/详情 → 右侧代码。类似 Chrome DevTools + Playwright Inspector 混合体。

优点

  • 信息密度高，一屏看全
  • 代码实时联动，方便修改
  • VS Code 原生三栏体验

缺点

  • 空间紧张，截图小
  • 复杂度高，实现成本大
  • 信息过载，审核体验差

方案 C：幻灯片式

每一步占满整个编辑区，类似 PPT 放映。底部导航条切换步骤，左右切换。

优点

  • 截图最大，视觉沉浸
  • 聚焦当前步骤，不分散注意力
  • 简单直观

缺点

  • 无法纵览全局流程
  • 定位特定步骤需要来回翻
  • 不适合步骤多的场景
