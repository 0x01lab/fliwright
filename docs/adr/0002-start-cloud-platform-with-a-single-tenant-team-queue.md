# Start the cloud platform with a single-tenant team queue

The first cloud-platform deployment is a self-hosted, single-tenant TeamTestQueue. Team members submit E2E test requests through the web interface or API, and retrieve execution status, reports and artifacts from the same service. GitLab CI acts as a queue client; team-operated workers exclusively own the registered devices. This keeps device access, credentials, builds, and test data within the team's environment while validating managed execution before taking on multi-tenant isolation and operations.

The team cloud-platform design authorized on 2026-10-18 brings the dashboard into the first delivery, superseding the earlier API/CLI-first delivery order. The private `@fliwright/cloud` package contains the server, Mac worker and CI client. Multi-tenant SaaS and live video remain separate follow-up work. See [design](../superpowers/specs/2026-10-18-team-cloud-platform-design.md) and [implementation acceptance](../superpowers/plans/2026-10-18-team-cloud-platform.md).
