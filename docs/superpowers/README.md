# Design And Plan Archive

This directory contains focused design records and execution plans. It is
historical context, not a bootstrap document.

- For a known feature, open its matching file in `specs/` or `plans/`.
- For an unknown feature, search titles with `rg` before opening a document.
- If a design links a parent design, open that parent only when the child does
  not answer the active question.
- Resolve conflicts in favor of current source, executable tests, and
  `docs/features/`; see
  [../../harness/specs/README.md](../../harness/specs/README.md) for the
  authority and lifecycle rules.
