# Fliwright Cloud 项目导航与看板草图

[打开可点击草图](./prototypes/cloud-project-navigation/index.html) · [项目目录](./prototypes/cloud-project-navigation/projects.png) · [项目用例板](./prototypes/cloud-project-navigation/workspace.png) · [团队执行板](./prototypes/cloud-project-navigation/board-light.png)

这版把 Trello 的工作区、横向列表和卡片详情用于两个不同的任务。维护用例的人先选项目和扫描版本，以套件为列浏览用例。值班的人从团队执行看板开始，以调度阶段和结果为列追踪每次提交。一条用例可以运行多次，产生多张执行卡。[设计依据](../../plans/2026-11-22-trello-cloud-ui-ux-guide.md)

## 入口与落点

| 从哪里进入 | 打开后看到什么 | 能做什么 |
| --- | --- | --- |
| 顶栏「项目」 | 团队项目目录。封面、项目名、仓库路径和默认分支共同标识项目 | 搜索项目、进入项目。管理员可以创建项目 |
| 项目卡 | 默认打开该项目的测试用例。每列一个套件，每张卡一个用例 | 切换扫描版本、搜索用例名称或路径、提交单条用例或整个套件 |
| 当前项目名 | 可搜索的项目切换器，当前项目旁有勾 | 输入名称或仓库，方向键选择，Enter 切换，Esc 回到项目名 |
| 顶栏「执行看板」或首页 | 团队所有项目的测试请求 | 跟进排队、执行与结果，按应用筛选或搜索分支、提交、任务 ID |
| 顶栏「测试报告」 | 已发布报告的运行 | 查看步骤，定位失败证据 |
| 顶栏「更多」 | 运行概览、执行资源 | 查看团队统计、设备与 Worker 摘要 |

## 项目内怎样找用例

项目左侧保留五个分区：测试用例、运行场景、运行记录、扫描记录和项目设置。窄屏时项目名和分区放到内容上方。项目封面与用例板背景共用一套配色，仓库路径始终可读。两个名为 Exio App 的示例分别来自 `mobile/exio_app` 和 `merchant/exio_app`。

选择扫描版本后，每个套件内显示该版本的用例。卡面显示名称、测试文件和该版本最近一次请求的状态。点击卡片可以查看完整版本、打开最近运行或提交新运行。套件列底部的「运行套件」提交当前版本内整个套件，即使列表已被搜索收窄。确认框展示仓库、版本和可选场景。提交后进入本项目的运行记录。

切换到另一个项目会打开它的测试用例。浏览器后退可恢复原项目的分区、筛选和阅读位置。项目、分区和筛选条件写入地址，支持复制链接和刷新。草图采用井号路由，如 `#/projects/exio?view=runs&state=fail`。[切换器预览](./prototypes/cloud-project-navigation/switcher.png) · [手机项目布局](./prototypes/cloud-project-navigation/mobile-project.png)

## 怎样跟进一次失败

团队执行看板在全局导航下使用一行 44 px 工具栏。左侧为板名，右侧为「筛选」和「提交测试」。点击「筛选」后可搜索提交、分支或任务 ID，也可按应用筛选。启用条件后，按钮上显示条件数，任务列保持原位。

执行卡展示请求 ID、用例或套件名、项目和仓库、阶段、分支及提交版本。调度状态决定卡片所在列。执行中的部分结果保留在「测试中」。排队卡按调度顺序显示位置，「其他结果」收纳已取消、已跳过等记录。列头数字是当前筛选下该状态的任务总数。每列独立纵向滚动，接近列底时自动追加下一批，直到读完。

打开「已失败」中的「提交订单后显示确认页」，可进入本次运行的报告，点「跳到失败步骤」展开断言与日志。同列的「执行异常」展示 Worker 中断的任务动态。关闭详情后，保留筛选、已加载的卡片和各列阅读位置。窄屏可在看板内横向滑到失败列。[失败详情](./prototypes/cloud-project-navigation/failure.png) · [深色看板](./prototypes/cloud-project-navigation/board-dark.png) · [手机看板](./prototypes/cloud-project-navigation/mobile.png)

## 评审时可以直接试

1. 从项目目录打开 `mobile/exio_app`，进入「运行记录」并筛选「已失败」。点击项目名，输入 `Exio`，按 ↓、Enter 进入 `merchant/exio_app` 的测试用例，再用浏览器后退。
2. 在 `mobile/exio_app` 的交易流程列打开一个用例，确认版本与场景后提交。到团队执行看板按新任务 ID 搜索，同一张卡会从等待设备进入执行，再进入已成功。
3. 从右上角头像切换到「新建团队」，分别用普通成员和管理员查看空目录。管理员创建示例项目后可发起首次扫描，生成目录后可在设置中确认就绪。已有的 Flutter Demo 也可用于走查首次扫描。

本草图使用本地示例数据，扫描、调度和报告均为模拟。刷新会保留当前标签页的演示进度。深浅主题由右上角的主题按钮切换。直接用浏览器打开同目录的 `index.html` 即可操作。
