# Commit And PR Guidelines

Git history uses Conventional Commit style such as `feat(mcp): add fliwright_run
tool`, `fix(core): call service extensions with isolate id`, and `chore: ignore
flutter generated files`. Keep messages scoped and imperative.

Pull requests should describe the behavior change, list test commands run, link
related issues or design docs, and include screenshots or logs for Flutter/UI or
E2E changes. Note any required VM service URL or device setup.
