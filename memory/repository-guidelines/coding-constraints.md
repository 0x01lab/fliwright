# Coding Constraints

TypeScript uses ESM, strict mode, Node16 module resolution, and ES2022 targets.
Keep source files in `src`, export public APIs from `src/index.ts`, and include
`.js` extensions in relative imports. Use PascalCase for classes and types,
camelCase for functions and variables, and `*.test.ts` for Vitest tests.

Dart code follows standard `dart format` conventions with two-space indentation.
Use snake_case filenames, PascalCase classes, and camelCase members.
