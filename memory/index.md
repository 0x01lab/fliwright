# Memory Index

This directory stores repository memory for agents. Start here, then open only
the linked documents needed for the task at hand.

## Required First Read

- [Repository Guidelines](./repository-guidelines/index.md) - project layout,
  coding constraints, commands, tests, workflow, security, and feature
  documentation routing.

## Progressive Disclosure Rules

- Always read this file before using repository memory.
- Always read the required first-read index before editing, testing, reviewing,
  or documenting this repository.
- From each sub-index, open the smallest set of leaf documents relevant to the
  current task.
- When source code changes significantly, update the related memory or feature
  documentation if the change affects how future agents should work.
