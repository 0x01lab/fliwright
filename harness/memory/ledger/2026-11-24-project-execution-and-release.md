## Decision

Keep a worker's catalog checkout associated with the project, commit and configuration revision used for discovery. Validate the saved checkout before running a request and resolve project-relative secure files on the worker. The project workspace brings together requests, workers, diagnostics, replay and catalog status.

Record the confirmed Flutter reload or restart result for each TDD cycle attempt. Preserve the first failure when a restart retry cannot produce a test result.

Release the public npm dependency graph at one version. Keep the CLI version, catalog metadata and generated project dependency ranges aligned with the package manifests. The VS Code extension and Codex plugin use independent version tags.
