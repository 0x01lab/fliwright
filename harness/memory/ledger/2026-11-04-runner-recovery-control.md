## Decision

Simulator boot timestamp plus PID cannot exclude PID reuse within one boot. A future restorer must authenticate the current Runner generation and request that process to end itself, rather than terminate whichever process now owns a remembered PID or bundle. The control primitive uses Apple Network on loopback and CryptoKit HMAC with a fresh challenge, direction-separated messages and exact session/generation/device/boot/PID binding. It accepts only identify/shutdown, bounds connections and frames, rejects replay and never signals another process. A shutdown ACK proves acceptance, not platform absence or baseline restoration.

Node transport freezes endpoint identity, sends each shutdown at most once per client and fences later requests even after a lost reply. Transport/protocol errors expose fixed messages without frames or secret material. Swift protocol tests compile the actual production control source; Node fake-peer tests alone cannot prove cross-language authentication. Runner preparation hashes every Swift source, including the control source, to prevent reuse of a stale protocol binary. System frameworks, source roster and Xcode membership remain governed together.

The transport experiment holds the normal device lease, refuses quarantined devices and writes a Runner launch/PID journal before/after launch. Its temporary XCTest entry kills only its private broker; that is not a lease-owner crash. Production testServe is now wired separately: protocol v2 requires the recovery port, schema v2 journals persist private credentials before xcodebuild dispatch, and platform identity plus a signed identify must pass before running checkpoint. Normal teardown authenticates and requests self-shutdown, waits for owned host work and reads back platform absence. No simctl terminate fallback remains. Startup and cleanup each share one total budget; unknown shutdown is never replayed. Legacy v1 journals cannot authorize recovery.

Separate production validation runs two real start/screenshot/stop cycles, then a true owner SIGKILL experiment on a disposable Simulator. The latter confirms host-group exit, Runner absence, unchanged journal and acquire rejection. It retains evidence and exclusion instead of cleaning it by hand. Neither successful self-shutdown nor Runner absence implements restore transactions or quarantine retirement; biometric/camera support is unchanged.
