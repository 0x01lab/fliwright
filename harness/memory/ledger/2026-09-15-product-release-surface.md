## Decision

Fliwright is released as Flutter-specific white-box E2E infrastructure with a CLI-authoritative product surface. The CLI owns scriptable commands and reusable capability seams; MCP is an optional thin adapter with an eight-tool intent-level core and legacy granular tools behind specialist/full profiles. Every public TypeScript package must expose publish metadata, contain only built artifacts/docs/licenses, and pass both npm and pnpm clean-consumer installation/import checks. The base Flutter bridge must remain free of optional Design QA dependencies, and release builds must not initialize VM-service automation or mock extensions. Generated Flutter smoke must exercise bridge startup, VM discovery, CLI execution, and structured report persistence in CI.
