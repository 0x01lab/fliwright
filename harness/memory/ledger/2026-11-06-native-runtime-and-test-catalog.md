## Decision

Discover runnable test identities through Vitest collection instead of a source
parser. Collection must remain lazy and cancellable, preserve exact collected
names for focused runs, and refresh execution status without discarding unrelated
case history. Keep the collector worker in the extension bundle.

Keep TDD responsible for execution, Flutter synchronization and resource cleanup.
The agent owns test authoring and evaluates whether a failure proves missing
behavior; do not reintroduce InteractionSpec generation or automatic repair loops.
Use named composed scenarios and app-owned authentication seeds for reusable app
state, with task preparation metadata retained through Vitest registration.

Native recovery must retain device exclusion while any owned host group or
unresolved platform evidence survives. Host inventory accepts Linux kernel
threads with process group zero, but still validates the owned wrapper and group
before permitting cleanup. XCTest session lifecycle tests run on macOS; Linux
continues to test the shared process ownership and recovery contracts.

Release verification builds the CLI before running documentation tests because
source-derived command references import the built command registry. Run the
complete quality gate on the exact main commit before publishing either plugin.

Keep Node type peers aligned across the workspace, including the root Vite
installation. Divergent peer versions create separate Vitest runtime instances;
custom runners and test modules can then disagree on the active suite even when
the Vitest package versions match. The scenario-registration subprocess test
reproduces this failure and protects test registration after peer alignment.

When asserting subprocess test summaries, strip ANSI control sequences before
matching counts; CI enables color and can otherwise make a correct run fail its
outer regression test. Durable Android recovery integration tests budget fixture
setup, fsync and crash-owner transitions separately from production operation
deadlines. Their outer test timeout must cover that complete sequence.
