# Operational Memory

This directory stores durable repository facts that are not universal coding
constraints. Open one leaf only when its subject is active.

- [project-structure.md](./project-structure.md): source, test, example, and
  runtime-state locations.
- [runtime-configuration.md](./runtime-configuration.md): VM Service URL
  resolution and local runtime configuration.
- [feature-documentation.md](./feature-documentation.md): reading and
  regenerating implementation reference.
- [development-conflict-policy.md](./development-conflict-policy.md): resolving
  active-design conflicts.

Commit and pull-request process belongs to
[../workflows/delivery.md](../workflows/delivery.md), rather than operational
memory.
